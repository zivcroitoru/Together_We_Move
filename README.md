# Prototype 3: Together We Move

## Overview
Two kids control two different characters (Blue and Red) on the same screen. They must help each other open paths and get through doors. Both must reach the end to win.

---

## How It Works
* **Two Characters:** Each kid has their own character.
* **Helping Roles:** One kid holds a switch while the other kid crosses.
* **Finish Together:** Both characters must reach the end star.

---

## Levels

| Level | Name | What to Do | Main Goal |
| :--- | :--- | :--- | :--- |
| **1** | **Hold the Platform** | Blue steps on a button so Red can cross. Red pulls a lever so Blue can cross too. | Learn patience and help first. |
| **2** | **Take Turns Leading** | Red opens a bridge for Blue. Blue opens a gate for Red. | Take turns helping and moving. |
| **3** | **Stay Together** | Stay inside a glowing circle while walking. If you move too far apart, bridges vanish. | Walk at the same speed and watch your partner. |

---

## Key Benefits
* **Clear Roles:** Each kid knows which character is theirs.
* **Simple & Calm:** Easy art and clear goals reduce stress.
* **Real Teamwork:** Kids must ask each other before letting go of buttons.
